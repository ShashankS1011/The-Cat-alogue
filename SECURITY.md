# Security Policy 🔒

## Supported Versions

We actively maintain and provide security updates for the latest stable release of **The Cat-alogue**.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of **The Cat-alogue** very seriously. If you believe you have discovered a security vulnerability in this project, please report it privately rather than opening a public issue.

### How to Report

1. **Email / GitHub Private Advisory**: Please send security reports directly to the maintainer or submit a **Private Vulnerability Report** via the repository's Security tab on GitHub.
2. **Details to Include**:
   - A clear description of the issue.
   - Steps to reproduce the vulnerability (proof of concept code or instructions).
   - Potential impact if exploited.

### Our Security Response Process

- **Acknowledgment**: We will acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment**: We will evaluate the impact and scope of the reported vulnerability.
- **Resolution**: If validated, a security patch will be prepared, tested, and released promptly.
- **Disclosure**: Once fixed, we will publish a security advisory giving full credit to the reporter (unless you prefer to remain anonymous).

Thank you for helping keep **The Cat-alogue** safe! 🐱
